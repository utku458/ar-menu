# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub:
**Security → Report a vulnerability** on this repository
(or email altinayutku0@gmail.com).

Include what you found, how to reproduce it, and the impact you expect.
I aim to acknowledge reports within a few days.

## Scope

This is a personal portfolio project. Only the code in this repository is
in scope. Demo and seed data are intentionally public and contain no real
user information.

## Supported versions

Only the latest commit on the default branch receives fixes.
